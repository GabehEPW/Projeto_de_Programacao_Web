## Descrição do projeto

O NexusPC é uma aplicação web voltada para auxiliar usuários na organização e montagem de configurações de computadores.

Nesta etapa do projeto, o desenvolvimento foi concentrado na camada frontend, seguindo a orientação recebida após a Etapa 1. Foi implementado um fluxo funcional de gerenciamento de peças de computador, permitindo cadastrar, consultar, editar e excluir componentes.

Além do CRUD de peças, o sistema também possui uma tela de montagem de computador, onde o usuário pode selecionar os componentes cadastrados e visualizar o preço total e o consumo estimado da configuração.

## Relação com a proposta da Etapa 1

Na Etapa 1, o projeto NexusPC foi proposto como uma plataforma para auxiliar usuários na montagem, configuração e atualização de computadores, reunindo informações sobre componentes de hardware, compatibilidade entre peças e estimativas de consumo energético.

Para a Etapa 2, foi escolhido um fluxo central da aplicação: o gerenciamento de componentes de hardware. O foco foi a construção da interface, organização dos componentes e desenvolvimento de uma base frontend funcional, utilizando dados simulados e armazenamento local.
